Installation

  1. Sur WordPress : Extensions › Ajouter › Téléverser le fichier de l'extension, puis activez-la (« Activer sur le réseau » en multisite).
  2. Sur Android : installez l'application (autorisez l'installation depuis cette source si Android le demande).
  3. Connexion : dans WordPress, Réglages › Remote Updater › « Générer un code de connexion », puis scannez le QR code avec l'app.
